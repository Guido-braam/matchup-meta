# Data and sprites are reused with the sources' one-time permission

Trainerhill and Limitless gave one-time permission to reuse their data on this public site, so the scripts keep using the endpoints they use today (including Trainerhill's internal one) and the deck sprites stay embedded in the data rather than linked. We do not ask again on each change. Without this, the default would have been Limitless's documented API only and linked or no images, because Trainerhill's published terms forbid scraping and the sprites are Nintendo's.

Card images and card data are a separate source: see ADR 0005.
